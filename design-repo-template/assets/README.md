# Assets

Use this folder for portfolio-safe visual material:

- Product screenshots with private data removed.
- Annotated UI screenshots.
- Interaction flow diagrams.
- Design system boards.
- Before/after comparison images.
- Short demo GIFs or videos, if appropriate.

Do not include:

- Real personal email addresses.
- API keys, OAuth tokens, passwords, or account credentials.
- Private email bodies or private attachments.
- Screenshots that imply production scale or user adoption that has not been validated.

Recommended naming:

- `01-inbox-overview.png`
- `02-mail-detail-ai-assistant.png`
- `03-compose-attachments.png`
- `04-undo-send-flow.png`
- `05-settings-privacy-ai.png`
