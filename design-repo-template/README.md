# MiNiMail Design Case Study

MiNiMail is an early-preview AI-native desktop email client designed for people who need faster triage, safer AI assistance, and more reliable compose workflows.

This repository is intended to host the UI/UX design case study for MiNiMail. The application source code and release engineering work live in the main product repository.

## Project Status

- Product stage: early preview / release candidate.
- Platform focus: Windows desktop.
- Product type: AI-native email client.
- Design focus: privacy-aware AI assistance, dense email triage, attachment workflows, draft recovery, and trustworthy compose behavior.

This case study should not claim large-scale adoption or full production stability unless that becomes true later and can be supported with evidence.
