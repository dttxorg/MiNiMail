# MiNiMail

[简体中文](../README.md) | [English](README.en.md) | 日本語 | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Português](README.pt.md)

MiNiMail は、日常のメールをより読みやすく、理解しやすく、処理しやすくするための AI ネイティブなデスクトップメールクライアントです。

ローカル優先のメールキャッシュと、プライバシーに配慮した AI 機能を組み合わせ、長いメールの要約、重要情報の抽出、返信下書き、翻訳、メールのスマートルーティングを支援します。

> 現在の状態: MiNiMail は release candidate 段階です。テスト、デモ、早期フィードバックには適していますが、重要な本番メール運用での利用はまだ推奨していません。

## 主な特徴

- メール一覧、本文、添付ファイルのメタデータをローカル優先でキャッシュします。
- AI 要約、返信提案、翻訳、ルーティング、構造化された重要情報抽出に対応します。
- 汎用 AI カテゴリに加えて、GitHub 通知メール向けの専用ルーティングを提供します。
- OpenAI 互換 API とローカル大規模言語モデルに対応し、クラウドモデルとローカルモデルをユーザーが選択できます。
- リモート画像とトラッキングピクセルをデフォルトでブロックします。
- HTML メールを表示前に安全にサニタイズします。
- 作成、下書き、添付ファイル、送信済みメールの復元、5 秒間の送信取り消しに対応します。
- 多言語 UI と多言語 README ドキュメントをサポートします。

## プライバシーモデル

MiNiMail の AI 機能は、ユーザーが制御できることを重視して設計されています。

- OpenAI 互換 API とローカル大規模言語モデルに対応し、クラウドモデルとローカルモデルをユーザーが選択できます。
- メール処理はプライバシーを意識して設計されています。
- リモート画像とトラッキングピクセルはデフォルトでブロックされます。
- HTML メールは表示前にサニタイズされます。

## 現在のプラットフォーム

MiNiMail は現在、主に Windows デスクトップアプリに注力しています。

技術スタック:

- Electron
- TypeScript
- ローカル優先のメールキャッシュ
- IMAP / SMTP / OAuth アカウントフロー

## ロードマップ

MiNiMail は現在 Windows デスクトップ体験の改善を優先しています。アーキテクチャが安定した後、次の方向を検討する予定です。

- macOS デスクトップ対応。
- iOS、Android、その他の可能なプラットフォームを含むモバイル体験。
- より充実したローカルプライバシーモードと AI メール知識機能。
- より完全なデザインシステム、インタラクション文書、多言語ドキュメント。

これらは安定性、保守コスト、実際のユーザーフィードバックに基づいて段階的に進めます。具体的な公開時期は約束していません。

## リリース前

リリースまたは内部テストビルドを作成する前に実行してください。

```bash
npm run test:release
```

チェックが失敗した場合は、失敗項目をスキップしないでください。実際の回帰か古いテスト前提かを確認し、最小限で安全な修正を行ってください。
