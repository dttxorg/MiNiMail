# Screenshots

This folder is reserved for lightweight engineering screenshots used in README files, release notes, or implementation documentation.

Recommended files:

- `01-inbox-overview.png`
- `02-mail-detail-ai-assistant.png`
- `03-compose-draft-attachments.png`
- `04-settings-ai-privacy.png`
- `05-attachment-download-open.png`

Guidelines:

- Do not include real personal email addresses, API keys, OAuth tokens, private message bodies, private attachments, or account credentials.
- Prefer demo accounts, redacted content, or synthetic test emails.
- Keep raw product exploration, visual iteration boards, and portfolio screenshots in the separate design repository: `https://github.com/<designer-username>/minimail-design`.
- If a screenshot documents a bug or regression, name it with the date and issue context so it can be removed after the issue is resolved.
