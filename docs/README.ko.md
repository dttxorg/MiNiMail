# MiNiMail

[简体中文](../README.md) | [English](README.en.md) | [日本語](README.ja.md) | 한국어 | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Português](README.pt.md)

MiNiMail은 일상적인 이메일을 더 쉽게 읽고, 이해하고, 처리할 수 있도록 돕는 AI 네이티브 데스크톱 이메일 클라이언트입니다.

로컬 우선 메일 캐시와 개인정보 보호를 고려한 AI 기능을 결합해 긴 메일 요약, 핵심 정보 추출, 답장 초안 작성, 번역, 메일 스마트 라우팅을 지원합니다.

> 현재 상태: MiNiMail은 release candidate 단계입니다. 테스트, 데모, 초기 피드백에는 적합하지만 중요한 프로덕션 이메일 워크플로에는 아직 권장하지 않습니다.

## 주요 특징

- 메일 목록, 본문, 첨부파일 메타데이터를 로컬 우선으로 캐시합니다.
- AI 요약, 답장 제안, 번역, 라우팅, 구조화된 핵심 정보 추출을 지원합니다.
- 일반 AI 카테고리와 GitHub 알림 메일 전용 라우팅을 제공합니다.
- 사용자의 AI API Key를 사용하며 AI token을 재판매하지 않습니다.
- 원격 이미지와 추적 픽셀을 기본적으로 차단합니다.
- HTML 이메일은 렌더링 전에 안전하게 정리합니다.
- 작성, 초안, 첨부파일, 보낸 메일 복구, 5초 전송 취소를 지원합니다.
- 다국어 UI와 다국어 README 문서를 지원합니다.

## 개인정보 보호 모델

MiNiMail의 AI 기능은 사용자가 통제할 수 있도록 설계되었습니다.

- 사용자는 자신의 AI API Key를 사용합니다.
- MiNiMail은 AI token을 재판매하지 않습니다.
- 이메일 처리는 기본적으로 개인정보 보호를 고려합니다.
- 원격 이미지와 추적 픽셀은 기본적으로 차단됩니다.
- HTML 이메일은 렌더링 전에 정리됩니다.

## 현재 플랫폼

MiNiMail은 현재 Windows 데스크톱 앱에 집중하고 있습니다.

기술 스택:

- Electron
- TypeScript
- 로컬 우선 이메일 캐시
- IMAP / SMTP / OAuth 계정 흐름

## 로드맵

MiNiMail은 현재 Windows 데스크톱 경험 개선에 집중하고 있습니다. 아키텍처가 더 안정되면 다음 방향을 검토할 계획입니다.

- macOS 데스크톱 지원.
- iOS, Android 및 기타 가능한 플랫폼을 포함한 모바일 경험.
- 더 완성도 높은 로컬 개인정보 보호 모드와 AI 메일 지식 기능.
- 더 완전한 디자인 시스템, 상호작용 문서, 다국어 문서.

이 방향들은 안정성, 유지보수 비용, 실제 사용자 피드백을 기준으로 단계적으로 진행됩니다. 구체적인 출시 일정은 약속하지 않습니다.
